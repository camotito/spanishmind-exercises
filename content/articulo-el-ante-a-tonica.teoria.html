El + palabra femenina en singular

Cuando una palabra es femenina y la primera sílaba suena fuerte con A o HA, usamos el o un en singular para que suene mejor (el agua, un águila).

Tres reglas clave

1. Siguen siendo palabras femeninas. Los adjetivos van siempre en femenino:

  • el agua fría
  • el águila majestuosa

2. En plural vuelven a usar LA / LAS.

  • el agua → las aguas
  • el águila → las águilas

3. Los demostrativos NO cambian. Solo cambia el artículo (el/un). Los demás van en femenino:

  • esta agua
  • aquella hacha

Palabras más comunes

  • el agua / las aguas
  • el águila / las águilas
  • el alma / las almas
  • el hacha / las hachas
  • el hambre
  • el aula / las aulas
  • el ama de casa / las amas de casa
  • el ala / las alas
  • el ave / las aves
  • el área / las áreas
  • el arpa / las arpas
  • el arma / las armas
  • el ancla / las anclas
  • el hada / las hadas

Excepciones (aquí sí usamos LA)

  1. Mujeres o profesiones: la árbitra
  2. Letras: la a, la hache
  3. Nombres propios o lugares: la Ana de la que te hablé, La Haya
  4. Siglas: la AFE
