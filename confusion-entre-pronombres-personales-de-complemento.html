Confusion Entre Pronombres Personales De Complemento

¿Dónde está el ordenador? No encuentro.

💡 Use the direct object pronoun for the masculine singular noun 'el ordenador'.

¿Queréis coger el móvil? Podéis coger ahora.

💡 Attach the direct object pronoun for 'el móvil' to the end of the infinitive.

Fix the error: A tu amiga la doy un móvil nuevo.

💡 'A tu amiga' is the indirect object, so we must use 'le' instead of 'la' (laísmo is grammatically incorrect).

¿Cómo sustituimos 'el ordenador' en la frase: 'Vosotros encendéis el ordenador'?

💡 We use 'lo' because 'el ordenador' is a masculine singular direct object. Using 'le' for inanimate objects is an incorrect form of leísmo.

Replace the direct object 'el móvil' with the correct pronoun and place it before the conjugated verb.: Vosotros cogéis el móvil.

Fix the error: El piso es muy caro, pero le quiero comprar.

💡 'El piso' is a masculine singular object, so the direct object pronoun must be 'lo' (leísmo de cosa is incorrect).

A mis tías escribo una carta desde el piso nuevo.

💡 Use the third person plural indirect object pronoun.

Rewrite the sentence by attaching the direct object pronoun for 'el ordenador' to the infinitive.: Queremos coger el ordenador.
